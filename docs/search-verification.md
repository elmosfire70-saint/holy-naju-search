# 키워드 검색·검색 기록 검증

2026-10-31. 기존 문헌 DB에 키워드 검색 기준선과 결과 재사용을 구현했다.

## 구현 동작

- 현재 정상 추출 버전의 문단과 제목을 FTS5 trigram으로 검색한다.
- 기본은 모든 입력 단어가 제목 또는 같은 문단에 있어야 하는 검색이다. 구절 모드는 문자열 순서를 보존한다.
- 출처·언어·문헌 종류·발표일 범위와 반환 상한을 지원한다. 발표일이 없는 문헌은 날짜 범위에서 제외한다.
- 3글자 이상 검색어는 FTS5 후보와 문자 그대로의 포함 검사를 함께 사용한다. 짧은 검색어는 부분 문자열 검사로 보완한다.
- FTS 검색은 제목 가중 BM25, 짧은 단어만 있는 검색은 제목/본문 등장 횟수로 정렬한다. 점수는 작을수록 우선이며 확률이 아니다.
- 발췌와 제목의 강조 범위를 문자 인덱스로 반환한다. HTML을 생성하거나 원문 본문을 수정하지 않는다.
- 검색 조건·필터·방식·반환 상한·자료 세대·알고리즘 버전이 같으면 저장 결과를 재사용한다. 검색 이력은 매 요청 추가한다.
- 정상 빈 결과는 보관한다. 실행 실패 시 쓰기 전체를 롤백하고 오류로 반환하므로 빈 결과로 혼동하거나 재사용하지 않는다.
- --refresh는 새 검색 실행을 만들며 원문 사이트를 재수집하는 명령이 아니다.

## 과거 근거

결과는 문헌 버전과 문단 ID를 참조하고 당시 제목·출처·언어·URL·발표일·점수·발췌·강조 위치를 보존한다. 현재 원문이나 메타데이터가 바뀌면 새 검색은 새 세대로 실행되지만 과거 기록은 당시 결과를 연다.

## 검증 명령과 결과

`.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v`.

검색 테스트 10개와 기존 DB/추출/OCR 테스트 18개, 총 28개 통과했다. 생략된 테스트는 없다.

- 1~2글자 한국어, 조사 붙은 단어, 여러 단어와 구절 검색.
- 제목 가중과 원문에 대응하는 강조 위치.
- 출처·언어·종류·날짜 필터 및 연산자로 해석하지 않는 입력.
- 같은 단어 조건의 대소문자·공백·순서 차이 재사용과 요청별 원문 보존.
- 필터·모드·상한·명시적 refresh의 검색 실행 구분.
- 원문/메타데이터 변경 시 세대 갱신과 과거 결과 보존.
- 동일 파일 재가져오기는 불필요하게 세대를 갱신하지 않음.
- 부분 처리 버전 제외, 빈 결과 재사용, 실패 시 기록·색인 세대 롤백.
- 기존 버전 1 데이터 보존 마이그레이션과 미래 버전 거부.

## 실제 보관 자료

실제 DB를 바꾸기 전에 SQLite backup API로 `data/backups/before-search-v2.sqlite3`를 만들었다. 버전 2로 전환한 후 문헌 6건·버전 6개·문단 468개가 유지되는 것을 확인했다.

| 검색 | 결과 |
|---|---|
| 성체, 출처 naju, 상한 5 | 근거 2개 |
| 같은 검색 재실행 | 동일 실행 ID 재사용 |
| Eucharist, vatican/en, 상한 5 | 상위 근거 5개 |
| 사랑, user_import/ko | 합성 OCR 근거 1개 |
| 하루를 시작합니다, 구절 모드 | 합성 OCR 근거 1개 |

모든 반환 발췌가 보관 문단의 해당 위치와 일치하는 것을 확인했다. CLI search/history/show와 import_documents.py check가 통과했고 DB·파일 무결성 결과는 ok=true, problems=[]였다.

문헌 6건에서 직접 검색 API 최초 1회는 67.24ms, 같은 결과 재사용 1회는 11.57ms였다. 프로세스 시작 시간과 네트워크 수집은 제외했다. 이 단일 측정은 p95나 전체 수집 규모의 성능 보장이 아니다.

## 한계와 다음 단계

한국어 동의어·형태소·다국어 의미 검색·번역은 아직 없다. 1~2글자 검색은 후보를 순회하고, 세대 확인도 문헌판 메타데이터를 순회하므로 대규모 자료에서는 별도 색인 및 변경 카운터와 부하 평가가 필요하다. 문단 기준 결과이므로 같은 문헌이 여러 번 나올 수 있다. 웹 UI와 문헌별 결과 묶기는 후속 단계다.

기술 참고. [SQLite FTS5 trigram 및 BM25 문서](https://www.sqlite.org/fts5.html).

# 작업 관리

작업과 설계 이슈는 https://github.com/elmosfire70-saint/holy-naju-search/issues 에 기록한다.
연결된 GitHub 도구를 우선 사용하고 지원하지 않는 작업은 `gh` CLI를 사용한다.

- 이슈 작성 전 대상 저장소와 기존 이슈를 확인한다.
- 이슈 본문에 목적, 범위, 완료 기준, 선행 이슈를 기록한다.
- 선행 작업이 있으면 GitHub 의존성 또는 `Blocked by: #번호`로 명시한다.
- 검증 결과를 기록한 후 완료 처리한다.
- PR을 외부 요청 수집 창구로 사용하는 설정은 꺼 둔다.
